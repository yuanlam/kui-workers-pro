# 前端旧出口代码索引

`../original/frontend/src/` 按原目录保存完整文件，便于按符号或页面名称定位。

- `pages/ServersPage.vue` 提供手动 SOCKS5 表单、WARP 模式和状态提示。
- `composables/useKuiState.js`、`composables/useApi.js` 和 `utils/egressState.js` 保存优选状态、操作请求和出口显示逻辑。
- `app/AppShell.vue`、`app/TopBar.vue`、`app/DesktopNavigation.vue` 和 `app/MobileNavigation.vue` 保存页面注册与导航入口。
- `styles/app.css` 保存隧道页面样式。完整页面在本目录 `WarpTunnelPage.vue`。
